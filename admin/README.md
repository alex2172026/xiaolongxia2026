# 闽南文化博客 - CMS 后台

访问后台：**https://xiaolongxia2026.online/admin**

## 使用方法

1. 打开 https://xiaolongxia2026.online/admin
2. 使用 GitHub 账号登录（需要授权）
3. 登录后即可在线编辑文章

## 文章分类

- **闽南建筑** - /articles/architecture/
- **闽南美食** - /articles/food/
- **闽南戏曲** - /articles/opera/
- **闽南语** - /articles/language/
- **传统习俗** - /articles/customs/
- **宗教信仰** - /articles/religion/

## 注意事项

1. 每次修改后，CMS 会自动提交到 GitHub
2. Vercel 会自动检测到 GitHub 的更新并重新部署
3. 部署完成后，网站会自动更新
