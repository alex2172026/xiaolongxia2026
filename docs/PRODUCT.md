# 🎵 SONG AI - 产品设计文档 v2.0

> 歌词一键成歌 · 智能编曲平台

---

## 一、系统架构

### 1.1 核心流程

```
用户访问 → 注册/登录 → 获取积分 → 消耗积分生成歌曲 → 作品库
    ↓
充值/会员 → 获取更多积分 → 无限生成
```

### 1.2 积分体系

| 身份 | 积分规则 | 生成消耗 |
|------|---------|---------|
| **游客** | 可浏览，无法生成 | - |
| **注册用户** | 新人送 10 积分 | 2 积分/首 |
| **会员** | 无限生成 + 专属人声 | 免费 |

### 1.3 定价

| 套餐 | 价格 | 权益 |
|------|------|------|
| **月度会员** | ¥29/月 | 无限生成 + 高品质 + 商用授权 |
| **年度会员** | ¥259/年 | 月度会员权益 + 8折 |
| **充值积分** | ¥1/1积分 | 2积分=1首歌 |

## 三、功能模块

### 3.1 用户系统

| 功能 | 说明 |
|------|------|
| U1 | 手机号/邮箱注册 |
| U2 | 微信/QQ/抖音一键登录 |
| U3 | 新人注册送 10 积分 |
| U4 | 每日签到 +1 积分 |
| U5 | 作品库（我的歌曲） |

### 3.2 积分系统

| 功能 | 说明 |
|------|------|
| P1 | 查看当前积分 |
| P2 | 积分记录（获得/消耗） |
| P3 | 充值积分 |
| P4 | 购买会员 |

### 3.3 生成系统

| 功能 | 说明 |
|------|------|
| G1 | 检查登录状态 |
| G2 | 检查积分余额 |
| G3 | 扣除积分 |
| G4 | 调用AI生成（模拟） |
| G5 | 返回4个版本 |

## 五、API设计

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/register` | POST | 注册 |
| `/api/auth/login` | POST | 登录 |
| `/api/user/info` | GET | 获取用户信息 |
| `/api/points/balance` | GET | 获取积分余额 |
| `/api/points/recharge` | POST | 充值积分 |
| `/api/member/buy` | POST | 购买会员 |
| `/api/generate` | POST | 生成歌曲 |
| `/api/works` | GET | 我的作品列表 |
