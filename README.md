# 🎵 SONG AI - 歌词一键成歌

> AI智能编曲工具，只要输入歌词，一键生成歌曲

## 功能特点

- 📝 歌词输入 - 支持多段落结构
- 🎼 9种音乐风格 - 流行、摇滚、电子、民谣、R&B、古风、爵士、嘻哈、抒情
- ⏱️ 多种时长 - 30秒/1分钟/3分钟/4分钟/5分钟
- 🎤 10种人声选择 - 青叔音、甜妹音、少年音、御姐音等
- 🎸 自动乐器配置
- 🎵 一次生成4个版本
